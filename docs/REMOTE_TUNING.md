# 遠端調整參數（tuning.json）

只改數值時不用發新版：改 repo 根目錄的 `tuning.json`、推到 `main`，手機打開 App（最多每 10 分鐘抓一次）或按「設定 → 外觀 → 回答卡片的玻璃 → 測試回答卡片」就會套用。
只認下表的名稱與數字，超出範圍會被夾回範圍內，其他一律忽略；沒網路或檔案壞掉就用程式內建預設值。設定 → 外觀「允許遠端調整參數」可關。

範例：`{"g3_blur": 10, "card_damp": 0.4}`

| 名稱 | 範圍 | 預設 | 說明 |
|---|---|---|---|
| `g3_blur` | 0–40 | 8 | 液態玻璃：後面畫面的模糊（dp） |
| `g3_dark` | 0–2 | 1.2 | 液態玻璃：暗度倍率（1 = 跟底欄一樣） |
| `g3_rim` | 0–1 | 0.12 | 液態玻璃：邊緣細亮線 |
| `g3_elev` | 0–30 | 8 | 液態玻璃：外陰影高度（dp） |
| `g3_ambient` | 0–1 | 0.2 | 液態玻璃：環境陰影濃度 |
| `g0_*`、`g1_*`、`g2_*` | 見下 | 各檔不同 | 原本／通透／很透 三檔 |
| `g<檔>_blur` | 0–40 | 6／6／10 | 後面模糊（dp） |
| `g<檔>_dark` | 0–2 | 0.9／0.6／0.6 | 暗度倍率 |
| `g<檔>_tint` | 0–1.5 | 0.62／0.85／（不染色） | 染色深淺（第 2 檔以上不染色，此值不影響） |
| `g<檔>_lift` | 0–2 | 1／0.5／（不用） | 亮度落差（第 2 檔以上不用） |
| `g<檔>_mid` | 0–80 | 46／28／（不疊） | 中間糊層模糊（dp；第 2 檔以上不疊） |
| `stretch_k` | 0–8 | 3 | 功能、設定頁滑過頭的拉伸，在系統原本的上再額外放大幾倍（0＝系統原本的）；改了要重開頁面才看得到 |
| `card_stiff` | 100–1500 | 420 | 回答卡跟著鍵盤的彈簧硬度（越大越快） |
| `card_damp` | 0.2–1 | 0.5 | 彈簧阻尼（越小越 Q 彈） |

新增可調項目：在 `RemoteTuning.ALLOWED` 加名稱與範圍，程式用 `RemoteTuning.f(ctx, 名稱, 預設值)` 讀。安全規則、模型代號、傳檔協定參數不要放進來。

## 詞清單（只能「新增」，不能取代內建的）
`tuning.json` 裡可以放字串清單；App 比對時用小寫、直接找這個詞有沒有出現在句子裡（不是正規表示式）。每個詞 1–20 字，最多 50 個，控制字元會被去掉。

| 名稱 | 用在哪 | 說明 |
|---|---|---|
| `words_action_verb` | `Assist.looksLikeAction` | 「這句話是要操作手機」的動作詞（內建：打開、進入、前往…） |
| `words_action_object` | `Assist.looksLikeAction` | 要操作的項目詞（內建：設定、頁面、藍牙…） |
| `words_refusal` | `Assist.refusesToOperate` | 聊天助理說「我不能操作手機」的說法（內建：不能操作手機、cannot operate…） |

範例：`{"words_action_verb": ["開起來", "點進去"], "words_refusal": ["沒辦法幫你操作"]}`

注意：固定指令（開 Wi-Fi、開藍牙…）現在由便宜模型（Router）判斷，`Assist.COMMANDS` 裡的關鍵字清單沒有在比對，所以不需要也不能遠端調整。
