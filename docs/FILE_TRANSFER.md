# 裝置之間傳檔案（設計，尚未實作）

目標：我在另一台手機（之後也包括電腦）上，對助理說「把〇〇傳到我的手機」，檔案就會出現在我的手機上。
**只給使用者自己的裝置用。** 使用者的決定（2026-10-23）：配對一次之後自動傳，不每次確認；先做手機對手機，同一個 Wi-Fi；之後再做遠端與電腦版。

## 安全底線（不增加使用者麻煩）
1. **配對才能連**：沒配對過的裝置連不上；請求要簽章，檔案內容加密。
2. **只開放 `/sdcard`**：不開放 App 私有資料夾（`/data/...`，裡面有 `claude_key`）；路徑要正規化，擋掉 `..` 與連結跳出去。這條跟 CLAUDE.md 的金鑰規則一致，不能放寬。
3. **總開關**（設定 → 傳檔案，預設關）：要用時打開。
4. **每次有檔案被取走，發通知並記錄**（時間、裝置、路徑、大小），在 App 裡看得到。
5. **配對可以隨時取消**；取消後金鑰作廢。
6. 連續驗證失敗要鎖一段時間（防猜碼）。

## 階段
- **階段 1（先做）**：手機對手機、同一個 Wi-Fi、直連，不用伺服器。
- 階段 2：遠端（需要中轉伺服器，要先決定自己架還是第三方、費用、隱私）。
- 階段 3：電腦版（要先決定 Windows 還是 Mac、用什麼語言；App 只有 Android 版）。

## 配對（階段 1）
1. 手機 A 開「配對」頁：顯示 8 位數配對碼，開一個 60 秒的配對視窗。
2. 手機 B 輸入配對碼（不用相機）。兩邊用配對碼做一次挑戰回應，證明雙方知道碼，之後各自產生 32 位元組的長期金鑰，存在 App 私有資料夾（權限 600）。
3. 配對視窗外、或連續 3 次失敗：拒絕並鎖 5 分鐘。
4. 配對碼只用一次，用完即廢；長期金鑰才用在之後的傳輸。

## 傳輸
- 探索：`NsdManager`（mDNS）服務類型 `_phoneai._tcp`；找不到時可以手動輸入 IP。
- 協定：App 內建一個只在「總開關開啟」時才監聽的小伺服器（只綁區網位址）。
  - `GET /v1/list?path=…`、`GET /v1/find?name=…`、`GET /v1/file?path=…`、`PUT /v1/file?path=…`
  - 每個請求帶：裝置 id、時間戳、隨機數、HMAC-SHA256 簽章（用長期金鑰）；時間差超過 30 秒或隨機數重複就拒絕（防重送）。
  - 檔案內容用 AES-GCM 分段加密（每段 64 KB，金鑰由長期金鑰與隨機數衍生）。
- 接收的檔案放在 `/sdcard/Download/PhoneAI/`。

## 助理整合
- 助理指令（語音或文字）：「把 X 傳到我的手機」「從〇〇手機拿 X」「列出〇〇手機的下載資料夾」。
- 實作：聊天助理新增工具 `file_fetch(device, name_or_path)`、`file_list(device, path)`；先用 `find` 依檔名找，找到多個時請使用者選。
- 這些動作用 Haiku 就夠（不需要看畫面），所以不會增加自動操作的成本。

## 電腦版（階段 3，Windows）

- **語言與打包**：Python + `cryptography`（跟手機端的 P-256 配對、HMAC 簽章、AES-GCM 分段加密規格相同）。用 GitHub Actions 的 Windows 機器打包成單一 `.exe`，使用者不用自己裝 Python。
- **介面**（tkinter 視窗）：「開啟互傳」開關、「配對另一台」按鈕、已配對裝置列表、最近記錄、傳輸進度條。
- **協定**：與手機完全相同（UDP 探索 47322、TCP 伺服器 47321、同一組端點與標頭）。電腦版同時是客戶端與伺服器，手機的助理才能「從電腦拿檔案」。
- **分享範圍（使用者決定，2026-10-23）**：整台電腦的所有資料夾都可以被已配對的裝置存取（以目前 Windows 使用者的權限為準）。仍然只有配對過、有長期金鑰的裝置能連；每次請求都要簽章。視窗裡要有明確的開關與說明，讓使用者知道範圍是整台電腦。
- **收件位置（預設）**：`下載\PhoneAI`。
- **狀態**：程式已寫在 `windows-transfer/`：加密、配對、伺服器、客戶端、探索、視窗、停止。Linux 上測試全部通過：10 項（含與手機版 Java 程式碼雙向互通、配對確認碼一致、停止會刪掉未完成的檔案）。視窗（tkinter）與 `.exe` 還沒在 Windows 上實測，由 GitHub Actions（`.github/workflows/windows-transfer.yml`）打包。

### 電腦版 AI 對話（使用者決定，2026-10-23，尚未開始做）
- 只做文字輸入，不做語音。
